# kubyshka-bots

Два Telegram-бота для проекта «Кубышка» (FinAssist). Отдельный репозиторий —
не часть FinAssist/Finik-backend, но читает `Docs/*.md` оттуда для контекста.

## Бот 1 — `team_bot` (командный чат)
- `/task <текст>` — записывает задачу в общий расшаренный список Напоминаний
  iCloud (через CalDAV, под Apple ID владельца списка).
- `/ask <вопрос>` — отвечает на вопросы про проект, используя контекст из
  `Docs/BACKLOG.md`, `AI_CHANGELOG.md`, `RELEASE_NOTES.md`.

**Настройка списка Напоминаний (один раз, руками):**
1. На iPhone владельца (Apple ID из `.env`) — приложение «Напоминания» → создать
   список «Кубышка — задачи» → «Поделиться списком» → добавить команду.
2. На appleid.apple.com → Sign-In and Security → App-Specific Passwords →
   сгенерировать пароль для этого бота (НЕ основной пароль Apple ID).

## Бот 2 — `channel_bot` (публичный канал)
- Постит автономно каждые `POST_INTERVAL_HOURS` часов. Источник темы —
  по приоритету: очередь тем (`/addtopic`) → неиспользованная запись
  `AI_CHANGELOG.md` (переформулированная в юзкейс) → тема, придуманная моделью
  самостоятельно по общему контексту проекта.
- Отвечает в чате обсуждения при канале (`DISCUSSION_CHAT_ID`), если он задан —
  на явные вопросы (есть «?») или упоминания «кубышк*» в тексте, не на каждую
  реплику подряд (иначе выглядело бы навязчиво в живом community-чате).

Instagram/Threads — не реализовано: официальная публикация требует настроенный
Meta Business/Creator аккаунт + Meta-приложение на стороне владельца бренда,
это отдельный этап после Telegram.

## Запуск локально

```bash
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполнить руками, ключи никогда не коммитить
cp channel_bot/topics_queue.example.json channel_bot/topics_queue.json

python -m team_bot.main      # в одном терминале
python -m channel_bot.main   # в другом
```

## Секреты
Ключи (Telegram-токены, OpenAI-ключ, Apple ID app-specific password) — только
в `.env` (не коммитится, см. `.gitignore`). Никогда не передавать их текстом
в чате/тикете — только через файл на диске.

## Известные ограничения
- Реактивные ответы в ЧУЖИХ (не своих) тредах/группах, рекомендующие продукт —
  сознательно не реализованы: для большинства платформ это выглядит как
  спам/astroturfing без явного раскрытия, что это бот. Если понадобится —
  отдельное обсуждение с явными предохранителями (частота, раскрытие, ручная
  модерация первое время).
- `channel_bot` публикует полностью автономно без ревью человеком — решение
  осознанное (принято явно), но для нового бренд-голоса стоит какое-то время
  посматривать за первыми постами вручную.
